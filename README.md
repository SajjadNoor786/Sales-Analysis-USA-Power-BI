🧠 Power BI Sales Performance Dashboard

This Power BI project visualizes sales performance across regions, categories, and sub-categories.

📊 Key Insights
- Total Sales: 2.30M | Total Orders: 9.99K | Total Profit: 286.40K
- Highest sales observed in 2021.
- West & East regions generated the most revenue.
- Technology category contributed the largest share.
